# Tristan Louis – Portfolio Website

This repository contains the source code for my personal portfolio website. The site showcases my engineering experience, technical projects, and skills in software development, data engineering, and machine learning.
The website is built with a clean layout and simple structure, serving as a central place for recruiters, collaborators, and hiring managers to learn more about my work. 

---

### Overview

The portfolio highlights:

- **Technical Projects**
Machine learning pipelines, data engineering workflows, backend APIs, and automation tools.

- **Professional Experience**
Data Science Intern, Software Development Intern, and Data Engineering Fellowship projects.

- **Skills & Technologies**
Python, SQL, FastAPI, Flask, ML frameworks, data visualization, cloud tooling, and more.

- **Contact & Profiles**
GitHub, LinkedIn, and email for opportunities or collaboration.

---

### Features

-Clean, responsive front-end design

-Sections for About, Projects, Skills, and Contact

-Links to GitHub repos and live demos

-Lightweight static website (no backend required)

## How to Run Locally

1. Clone the repository
```bash
git clone <your_repo_url>
cd portfolio
```

2. Open the Website

Simply open `index.html` in your browser:

Double-click:
```
index.html
```

or run: 
```bash

open index.html
```

Since this is a static site, no additional setup is required. 

---


### Deployment

The site is deployed automatically through GitHub Pages.

To redeploy:

Commit any changes

Push to the `main` branch

GitHub Pages will update the live version
